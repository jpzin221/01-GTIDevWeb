# Desafio 01 — Checklist de Melhorias (UNIAENE GTI)

Bem-vindo(a) ao **Desafio 01**!  
Este repositório contém uma página simples (HTML/CSS/JS) com uma lista de **10 melhorias**.  
Cada melhoria concluída vale **1 ponto**. No fim do semestre, vamos somar os pontos (por aluno) e premiar quem pontuar mais.

---

## Regras (LEIA COM ATENÇÃO)

### ❌ Proibido commitar na branch `main`
**Qualquer commit direto na `main` desclassifica o aluno.**  
Trabalhe **sempre** em uma branch própria e entregue via Pull Request.

### ✅ Fluxo de entrega obrigatório
- Trabalhe no seu fork.
- Crie uma branch com seu nome.
- Abra apenas um **Pull Request** (PR) com as melhorias.

---

## Pontuação

- Este desafio tem **10 itens**.
- Cada item concluído = **1 ponto**.
- **Esses pontos não notas, é apenas uma forma de contabilizarmos as atividades feitas que no final valerão prêmios.**
- Você deve fazer **apenas um commit** para cada alteraçao realizada.
- A pontuação final será conferida pelo histórico de PRs/commits.

---

## Checklist de melhorias (10 desafios)

Você deve implementar melhorias no projeto seguindo os itens abaixo:

1) **Trocar o título da aba do navegador**
   - Atualize o conteúdo da tag `<title>`.

2) **Alterar o texto do H1 (título principal)**
   - Troque o texto do `H1` por algo como: `Desafio 01 — Seu Nome`.

3) **Adicionar um parágrafo de descrição**
   - Crie um `<p>` abaixo do título explicando o objetivo do desafio (2 a 3 linhas).

4) **Adicionar uma lista ordenada de regras**
   - Crie um `<ol>` com pelo menos 3 regras (incluindo a regra da branch `main`).

5) **Adicionar um link para o repositório**
   - Insira um `<a>` apontando para o repo da turma/organização.

6) **Adicionar uma imagem com texto alternativo**
   - Adicione uma imagem (pode ser um logo simples) usando `<img>` com `alt` bem escrito.

7) **Criar uma seção “Contato”**
   - Crie uma seção com `<h2>` + `<p>` e um e-mail fictício (ou da disciplina).

8) **Adicionar uma tabela simples**
   - Crie uma tabela com 2 colunas: `Desafio` e `Ponto`.
   - Preencha 3 linhas como exemplo.

### CSS

9) **Mudar a cor do fundo e a fonte**
   - No `style.css`, mude `background-color` do `body` e defina `font-family`.

### JS

10) **Mostrar um alert ao clicar em um botão**
   - Crie um botão no HTML: “Clique aqui”
   - No `scripts.js`, faça aparecer um `alert("Parabéns! Você concluiu o desafio!")` ao clicar.

> Observação: você pode propor melhorias equivalentes, mas **mantenha o escopo compatível** com 1 ponto por item.
